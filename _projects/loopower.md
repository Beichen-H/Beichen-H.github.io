**Loopower** is a contract-first skill library designed for Codex-native agent workflows.

### Key Features
- **Governed Delegation**: Replaces spontaneous delegation with verified, project-local contracts.
- **DAG Execution Governance**: Evidence-locked DAG topology to prevent unverified inline execution.
- **Host-Native Lifecycle**: Leverages Codex's native lifecycle APIs (`spawn_agent`) without requiring external runtime engines or background daemons.

Check out the full repository on [GitHub](https://github.com/Beichen-H/Loopower).
